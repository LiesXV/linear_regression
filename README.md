## 📋 Description

**ft_linear_regression** est le premier projet du cursus **Machine Learning** à 42.

L’objectif est d’implémenter **de zéro** un algorithme de **régression linéaire** en Python, sans utiliser de bibliothèque de machine learning (comme scikit-learn).

Le projet se divise en deux parties :
- **Partie obligatoire** : Entraîner un modèle de régression linéaire simple (une variable explicative).
- **Partie bonus** : Gestion de la régression linéaire multiple + visualisation + prédictions.

---

## 🛠️ Fonctionnalités implémentées

### Partie obligatoire
- Implémentation complète de la **régression linéaire** avec la méthode des **moindres carrés** (Least Squares)
- Calcul du coût (MSE - Mean Squared Error)
- Algorithme de **descente de gradient** (Gradient Descent)
- Normalisation des données (feature scaling)
- Sauvegarde et chargement du modèle (fichier `.model`)
- Prédiction à partir du modèle entraîné
